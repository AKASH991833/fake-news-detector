Model
Tokenize + stem + negation merge "did not work" → not_work
Bag-of-words text → binary feature vector
Logistic regression + L2 → positive probability
Occlusion remove word → measure score change

A linear bag-of-words model is the right size for a 123-headline corpus: every word gets one learned weight, so predictions stay stable and every verdict is fully explainable. Word explanations use occlusion: each word is removed and the score change is measured.

Ships with pre-trained weights for instant, deterministic results. Retrain locally any time — nothing leaves your device.

Honest limits — read this: this model checks writing style, not facts. It learned from 123 hand-written headlines that fake news often uses clickbait patterns (SHOCKING, one weird trick, they don't want you to know) and real news uses sober, specific language. It cannot verify whether a claim is true — a well-written lie will pass, and a sensational true headline will be flagged. Always verify with trusted sources. English only.
